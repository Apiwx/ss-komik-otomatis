# 📚 Manhwa Downloader & Scene Splitter

Automatisasi download panel manhwa dari **AsuraComic**, konversi ke JPG, dan pemotongan berdasarkan scene.

---

## 📦 Fitur Utama

- ✅ Download otomatis semua gambar di 1 chapter
- 🔁 Konversi `.webp` ke `.jpg`
- ✂️ Deteksi garis kosong dan potong per scene
- 📁 Struktur folder rapi otomatis

---

## 🚀 Cara Penggunaan

### 1. Unduh Gambar dari Chapter (Script: `main.py`)

#### 🔧 Ubah URL Chapter

Buka file `main.py`, cari baris:

```python
url = 'https://asuracomic.net/series/dungeon-architect-8704aab9/chapter/2'
```
